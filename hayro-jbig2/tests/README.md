# hayro-jbig2 tests

Each test decodes a JBIG2 file from `streams/` and compares the result against an image in `references/`.

The format of these tests was heavily inspired by the [JBIG2 tests of SerenityOS](https://github.com/SerenityOS/serenity/tree/master/Tests/LibGfx/test-inputs/jbig2).

Before submitting new reference images, optimize them with [oxipng](https://github.com/oxipng/oxipng):

```bash
oxipng -o max --strip safe hayro-jbig2/tests/references/*.png
```

## Provenance

The streams are generated by a JBIG2 encoder written for this test suite. Each test is marked as one or more of:

- **SerenityOS**: a rewritten version of a SerenityOS test file, covering the same features with different images.
- **Coverage**: covers a part of the specification that the SerenityOS tests don't.
- **Custom**: covers a code path that is specific to hayro's implementation, or a bug that hayro had.
