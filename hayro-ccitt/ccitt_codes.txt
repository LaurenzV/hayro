================================================================================
SUMMARY
================================================================================

Max code lengths:
  - White terminating: 8 bits
  - White make-up: 9 bits
  - Black terminating: 12 bits
  - Black make-up: 13 bits
  - Common make-up: 12 bits
  - Mode codes: 7 bits
  - EOL: 12 bits

Decoding white runs:
  1. Try WHITE_TERMINATING (0-63) - always ends a run
  2. Try WHITE_MAKEUP (64-1728) - adds to run, continue reading
  3. Try COMMON_MAKEUP (1792-2560) - adds to run, continue reading
  4. Check for EOL

Decoding black runs:
  1. Try BLACK_TERMINATING (0-63) - always ends a run
  2. Try BLACK_MAKEUP (64-1728) - adds to run, continue reading
  3. Try COMMON_MAKEUP (1792-2560) - adds to run, continue reading
  4. Check for EOL
