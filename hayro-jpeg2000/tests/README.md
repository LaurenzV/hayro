# hayro-jpeg2000 tests

Each test decodes a JPEG 2000 file from `streams/` and compares the decoded samples against an image in `references/`. Tests with the same expected result share a reference.

The streams are generated by the test generator in the `hayro-testgen` directory of the `hayro-testgen` branch of OpenJPEG, which also draws the references.

Each reference holds exactly the expected decoded image in 8 bits, as `DecodedImage::data_u8` returns it, with one channel per component. Images with more than four components are stored as one grayscale image with the components side by side.

Before submitting new reference images, optimize them with [oxipng](https://github.com/oxipng/oxipng), without changing their color type or bit depth:

```bash
oxipng -o max --nx hayro-jpeg2000/tests/references/*.png
```

## Provenance

The tests replace a suite of files from SerenityOS, OpenJPEG and hayro itself. Each test is marked with the files whose coverage it took over. **Custom** marks hayro's own files, which covered code paths specific to hayro's implementation or bugs that hayro had.
